UFC - Campus Quixadá

Um importante polo de tecnologia no Sertão Central. O campus é referência na formação de profissionais em áreas de TI, incluindo os cursos de Redes de Computadores, Engenharia de Software, Sistemas de Informação, entre outros.

Sobre o Projeto Front-End

Este layout foi construído com uma restrição técnica interessante: não utilizar JavaScript.

A navegação no estilo Single Page Application (SPA) foi recriada usando o truque dos botões de rádio ocultos no HTML. A tag <label> controla o estado da página, e o seletor irmão (~) no CSS cuida da exibição das telas.

Recursos Desta Versão:

  • HTML5 Semântico (`nav`, `section`, `main`)
  • Estilização completa via Tailwind CSS
  • Iframe do OpenStreetMap centrado em Quixadá
  • Navegação baseada em pseudo-classes CSS (`:checked`)
